# User Workflows

Version: 2.0

Status: Planning

---

# 1. Overview

The UORA Platform digitizes the complete lifecycle of academic publishing. Every user interacts with the system through predefined workflows based on their assigned role.

The platform supports workflows for:

- Public Readers
- Authors
- Reviewers
- Editors
- Managing Editors
- Editor-in-Chief
- Administrators

All workflows are integrated into one centralized platform.
