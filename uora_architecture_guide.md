# UORA Platform Architecture Guide

Here is a complete breakdown of your newly organized `uora-platform` repository. This guide explains what each folder is meant to carry and highlights the most critical files you'll interact with in the future.

---

## 1. `backend/` (The Engine)
This folder holds your Express.js API, Prisma ORM, and all database interaction logic.

*   **`src/`**: The heart of the backend.
    *   **`modules/`**: This is where all business logic lives. Each folder (e.g., `user`, `journal`, `submission`) contains its own routes, controllers, and services. *When you build a new feature, you will add a new folder here.*
    *   **`middlewares/`**: Contains security and verification code (like verifying JWT tokens or checking if a user is an Admin).
    *   **`config/`**: Setup files for third-party tools (e.g., database connection, file uploading).
*   **`prisma/`**: 
    *   **`schema.prisma` (⭐ CRITICAL)**: This file defines your entire database structure. If you need to add a new table (like `Comments` or `Payments`), you write it here.
    *   **`seed.ts`**: Contains script logic to populate your database with initial dummy data.
*   **`uploads/`**: Local storage for submitted PDFs and images before you eventually move to cloud storage (like AWS S3).
*   **`.env` (⭐ CRITICAL)**: Holds your secret keys (Database passwords, JWT secrets). *Never commit this file to GitHub!*
*   **`package.json`**: Lists all backend dependencies (like `express`, `bcrypt`, `prisma`).

---

## 2. `frontend/` (The Face)
This folder holds your Next.js React application, containing all the user interfaces, styling, and client-side logic.

*   **`app/`**: This utilizes Next.js App Router. Every folder here represents a URL route on your website.
    *   **`(auth)`, `(admin)`, `(author)`**: The parentheses `()` mean these are "Route Groups". They help you organize pages without changing the actual URL. For example, the author dashboard pages will live inside `(author)` but the URL might just be `/dashboard`.
    *   **`api/`**: Next.js serverless functions (if you choose to use them alongside your Express backend).
    *   **`page.tsx` (⭐ CRITICAL)**: The landing page (Home) file.
    *   **`layout.tsx` (⭐ CRITICAL)**: The master template for your website (contains the `<html>` and `<body>` tags, and global providers).
*   **`components/`**: 
    *   **`ui/`**: Usually reserved for dumb, reusable components (like a standard `Button` or `Input` field), often generated by `shadcn/ui`.
    *   **`layout/`, `forms/`, `dialogs/`**: Where you will build complex, specific components like a "Submit Paper Form" or "Reviewer Assign Dialog".
*   **`features/`**: For grouping logic that belongs to a specific feature (like all the frontend logic for peer-reviewing) so it doesn't clutter the components folder.
*   **`services/` (⭐ CRITICAL)**: This is where you will write functions to make API calls (using `fetch` or `axios`) to your `backend/`.
*   **`store/`**: For global state management (e.g., using Zustand or Redux) to remember who the logged-in user is across different pages.
*   **`tailwind.config.ts` & `globals.css` (⭐ CRITICAL)**: Where your global design system, colors, fonts, and Tailwind settings are defined.

---

## 3. `docs/` (The Blueprint)
This folder holds all your Markdown documentation.
*   *Important for the Future:* Whenever you make a major architectural change or add a new portal, you should update the files here so the development team always has a single source of truth.

---

## 4. `database/` (The Schemas)
*   *Important for the Future:* When you start designing complex ER (Entity-Relationship) diagrams or writing custom SQL migration scripts, they will be stored here for reference, separate from the actual Prisma ORM code.

---

## 5. `deployment/` (The Launchpad)
*   *Important for the Future:* When it's time to put this website on the internet (production), this folder will hold Dockerfiles, Nginx configurations, and CI/CD pipelines (like GitHub Actions) to automate the release process.

---

## 6. `scripts/` (The Tools)
*   *Important for the Future:* This will hold utility scripts, like a script to quickly backup the database, or a script to clean up old temp files.
